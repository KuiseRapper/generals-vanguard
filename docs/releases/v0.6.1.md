## Generals Vanguard 0.6.1

Everything in 0.6.0 stays: the self-installing Windows launcher, the **Mods** screen, and the retail
Zero Hour screens with only the Vanguard logo on them.

- **The shell's blue button borders are Vanguard purple now.** The button pieces of the retail shell
  atlas were recoloured (the hover border and hover text too), and the same border colour is in the
  shell layouts. The panels and backgrounds stay the retail blue.
- **A team game now ends when the last team is standing.** A 4v4 on Twilight Flame had all four
  enemies marked defeated in the player list and still sat in the match, because the engine knew the
  last alliance was standing but only a map script could declare it. The engine now runs the same
  Victory/Defeat action the script would. Campaigns and LAN keep their own scripts. If it still
  happens on a map, send the replay.
- **Launcher:** the self-install download handles the renamed file the release serves, so **Check for
  updates** replaces an older launcher and then updates the game in one pass.

Still needed on your machine: your own Zero Hour installation. No EA game data is in the launcher or
the game package. The macOS launcher is not part of this release.
