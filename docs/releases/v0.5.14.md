## Generals Vanguard 0.5.14

The game now comes to the front the moment it starts, instead of waiting for your first click.

- **The start-up window is raised.** A game the launcher starts is a child of a process that stays
  frontmost, and the game made its window without asking for the front: it was neither frontmost nor
  active, so the first click in it was a click that activated the application. On macOS that is the
  click reported as minimising the window. `SDL_RaiseWindow` (SDL's Cocoa backend turns it into
  `[NSApp activateIgnoringOtherApps:YES]` and `makeKeyAndOrderFront`) now runs once, before anything
  is drawn. Measured: before the change a launcher-style start left Firefox frontmost and the game
  inactive; after it, the game is frontmost and active.
- **Window state is logged** (focused, lost focus, minimised, restored, shown, hidden) so if it
  still disappears the debug log names the event and who did it.

The menu branding and the stock load screen from 0.5.13 are unchanged.

Version 0.5.14 game. The launcher is unchanged from 0.5.12.
