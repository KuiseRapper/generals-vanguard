## Generals Vanguard 0.5.9

The first performance fix for the GPU coil whine.

- **VSync is on by default.** The renderer was drawing ~118 frames a second on a 61 Hz panel, which
  is what makes a GPU whine while the game is only idling in the menus. A fresh install now waits for
  the monitor; the Options > Display checkbox still turns it off for anyone who wants the old
  uncapped picture.
- Next in the performance line (see [ROADMAP.md](../../ROADMAP.md) and [BACKLOG.md](../../BACKLOG.md)):
  an explicit frame cap, then a selectable Vulkan backend through SDL3's GPU layer, measured against
  D3D11 on the owner's Windows machine.

Version 0.5.9 game and launcher.
