## Generals Vanguard 0.6.0

This release is the front door. Windows now has a **one-click launcher**, and it has the
**Mods** screen that was missing.

- **`VanguardLauncher.exe` is the download for Windows, and one run is enough.** It copies itself
  into `%LOCALAPPDATA%\Programs\Generals Vanguard`, which is writable so it can update itself,
  creates the Start Menu and desktop shortcuts, and starts the installed copy with `--install`. That
  path downloads the current game, checks its SHA-256, connects the Zero Hour files the game shares
  and repairs the per-user Zero Hour install path. No Program Files, no manual folder moving, no
  administrator prompt. `--portable` leaves a developer build where it is.
- **The launcher has a Mods button.** It lists **Vanguard Combined**, **ShockWave 1.201** and
  **Rise of the Reds 1.8** before anything is installed, with the size of each package. Nothing is
  downloaded until you press Download. A mod is unpacked into
  `Documents\Generals Vanguard\Mods\<id>`, gets a `mod.json` for the version line, and is mounted by
  Play with `-mod`. Tick one to play it; tick none to play vanilla Vanguard.
- **The three mods are not bundled** and the game update never touches them, so updating the game
  cannot delete a mod you downloaded.
- The optional Inno Setup script in `Tools/VanguardInstaller` builds a `VanguardSetup.exe` for a
  packaged deployment, but the release does not need it: the launcher installs itself.
- The launcher's version is now 0.6.0, so **Check for updates** replaces an older launcher itself.

- **The shell's blue button borders are Vanguard purple.** The button pieces of the retail shell
  atlas were recoloured (hover border and hover text too); the backgrounds stay the retail blue.
- **A 4v4 now ends when the last team is standing**, even if the map's own Victory script misses it;
  a Twilight Flame 4v4 had all four enemies marked defeated and still sat in the match.
- **The screens are Zero Hour's again, with only the Vanguard logo.** The splash, load screens,
  credits, challenge, faction pages, end screens and the main menu's frame/backdrop are the retail
  Zero Hour art, forced over the mods'; the supplied Command & Conquer Generals VANGUARD logo replaces
  the Zero Hour wordmark on the splash, title/load screen, load page and main menu. The 0.5.18 custom
  plates are gone.

Still needed on your machine: your own Zero Hour installation. No EA game data is in the launcher or
the game package.
