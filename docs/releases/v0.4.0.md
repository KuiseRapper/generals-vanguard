## Generals Vanguard 0.4.0

**You do not need a separate Generals install.** Zero Hour already carries the base game's shared
art, sound and music; the launcher now links those files into its own `ZH_Generals` folder from your
Zero Hour install (or from a separate/Steam Generals folder if that is where they live). If Windows
will not create the link, it copies the `.big` files instead.

- **Base game files are linked automatically.** The old "Install Generals..." warning is gone for a
  normal Zero Hour install. The launcher finds `ZH_Generals` next to Zero Hour, a registered Generals
  install, or the Steam sibling, and links it before Play.
- **New launcher window.** Hero art, game and launcher versions, a clear Play button, Zero Hour and
  base-file status, and a `Locate Zero Hour` fallback.
- **Review/update screen.** Check for updates opens a screen with the release notes, the package
  size, and Update/Cancel before anything is written.
- **Icon.** The launcher has its own Vanguard star icon.
- **The game starts with `-rk7`.** That is the marker `WinMain` requires; the launcher passes it, so
  Play reaches the game instead of "Please start Generals Vanguard from its launcher."
- **Zero Hour, not the base game.** Detection reads the Zero Hour `InstallPath` in both registry
  views, Steam's library folders and the EA app defaults, and repairs a per-user path that points at
  a folder without `INIZH.big`.
- **Safer updates.** A game folder holding a `ZH_Generals` link is replaced without following the
  link, so an update cannot delete the base files in your Zero Hour install.

This release contains the same game build as 0.3.2; the launcher is what changed.
