## Generals Vanguard 0.5.17

The shell screens are Zero Hour's own again - original layouts, font sizes and positions - with only
the logo and the images replaced by Vanguard's.  That also brings the animated 3D shell-map
background back, because the mods' menu layouts drew a static backdrop over it.

- The mod's 59 shell menu layouts (`Window/Menus/*.wnd`) are overridden with retail's, the fork's
own where it already had one (the skirmish screen with its AI box, the Victorious/Defeat plates).
- The main menu is the retail layout: normal fonts, the familiar button stack, Vanguard's wordmark
  and the live shell map behind it.
- Still known: some EU models go black mid-match, and the faction load pages are still the mods' art.

Version 0.5.17 game.
