## Generals Vanguard 0.4.3

- **Fixes the `Data\INI\GameData.ini` / `UserDataLeafName` crash.** Some Zero Hour SKUs carry a
  second `INIZH.big` in `Data\INI`; the retail game deletes it at startup, but Vanguard runs from
  its own folder, so the duplicate stayed and its Reforged 3.x `GameData.ini` won. Both launchers now
  move `Data\INI\INIZH.big` to `INIZH.big.vanguard-backup` before Play. The real `INIZH.big` in the
  Zero Hour root is left alone.
- **The V is centred** in the launcher hero, icon, startup splash and title screen (0.4.2 art).
- **The Reforged 3.x warning** stays for the root `INIZH.big`.
- macOS 0.4.3 has the same duplicate-file fix and the centred art.
