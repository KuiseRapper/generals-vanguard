## Generals Vanguard 0.4.5

- **Detects an incomplete Zero Hour install.** `Data\\INI\\Default\\Weather.ini` is inside Zero
  Hour's `INIZH.big`.  An uninstall/reinstall that leaves no `Weather.ini` there makes the engine
  throw during initialization; the launcher now checks the BIG and names the fix before starting.
- **Points the game at the detected Zero Hour folder.** The per-user `InstallPath` is always written
  to the install the launcher found, so a stale registry key after an uninstall does not send the
  game at a folder whose data is gone.
- The 0.4.4 retail `UserDataLeafName` parser fix stays.
