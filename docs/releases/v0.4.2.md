## Generals Vanguard 0.4.2

- **The V is centred.** The launcher hero, the Windows startup splash, the title screen and the icon
  all draw the V on the star's centre now.
- **Reforged 3.x data is detected.** The launcher reads `INIZH.big` for `UserDataLeafName`, the field
  upstream 3.2.0 added to `GameData.ini`. This fork is based on upstream 3.0.1 and stops on that
  field (`Error parsing INI file 'Data\INI\GameData.ini' ... UserDataLeafName`). Play now warns before
  starting, and the warning names the fix.
- **The fix for that crash** is a clean 3.0.1 Zero Hour, not a Vanguard patch: Steam → Zero Hour →
  Properties → Installed Files → Verify integrity, and move the Reforged extra `.big`/`ReforgedArt`
  files out of the Zero Hour folder. Reforged can be reinstalled separately afterwards.
- **macOS 0.4.2** has the same warning and the centred art; the DMG and game package are attached.

The Vanguard game code is still the 3.0.1-based fork; this release is art, the data warning and the
launcher. Merging upstream 3.2.0 is a separate, larger change.
