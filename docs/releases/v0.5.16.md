## Generals Vanguard 0.5.16

The RoTR factions' computers play, the main menu moves again, and the screens carry Vanguard's
branding.

- **The AI can play Russia and ECA.** They take RoTR's own skirmish-slot sides
  (`AmericaLaserGeneral`, `AmericaSuperWeaponGeneral`), and the RotR build lists are named for those
  sides. Before, a stock map had no side for a faction it had never heard of, so the AI seat found no
  skirmish scripts and `Player::initFromDict` turned it into a **human** player - it sat there and let
  you command it. ShockWave's two generals for those slots are `PlayableSide = No`, so the slots are
  the new factions' alone. Verified headless, same seed: **ECA 194 units built, won; Russia 139
  units, won.**
- **The main menu animates again.** The merged `GameData.ini` pointed `ShellMapName` at
  `ShellMapSHW`, a map inside the mod's own maps archive; maps are fork-owned, so that map was never
  listed, the shell map was not in the cache and the menu fell back to its static backdrop. It points
  at retail's `ShellMap1` again, and the 3D menu is back.
- **The load screen and the end screen are Vanguard's.** The load screen's plate is the fork's own
  Vanguard art (fork-owned, so a mod cannot put its red plate back), and the post-game screen draws a
  Vanguard plate instead of the mods' red one.
- Still open and known: some EU models render black in the middle of a match (they are textured at
  match start, so it is a runtime state, not a missing file), and the rest of the mod's screens
  (faction load pages, some menu frames) still show their own art.

Version 0.5.16 game; the combined mod package carries the data changes.
