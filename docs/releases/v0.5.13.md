## Generals Vanguard 0.5.13

The game is called Vanguard at the top of the screen too, and the load screen is Zero Hour's own
again.

- **The main menu logo** now reads GENERALS **VANGUARD** instead of the retail "GENERALS ZERO HOUR"
  mark. It is the fork's wordmark on its own texture (`ReforgedGeneralsLogo.tga`), reached by a
  HandCreated `GeneralsLogo` mapped image, so the shared retail atlas is untouched.
- **The window title** says "Generals Vanguard" with any mod loaded, ShockWave's included. One line
  in `Data/Patch.str` overrules both the retail CSF and a mod's `Generals.str`, because Patch.str is
  parsed last.
- **The load screen is the stock Zero Hour art again.** The fork's own Vanguard title art was a loose
  file that beat EnglishZH.big and every mod's title art with it; it is removed, and a mod may now
  supply its own.
- **The combined mod's two armies are named** in the lobby: Russian Federation and European
  Continental Alliance.
- **Fixed a red test suite**: the shipped VSync default is on (the frame cap work), and the RotR
  textures the Russia models load are now claimed as the fork's.

Verified on macOS arm64: built 0.5.13, `test_gameengine` passes (579k checks), and a windowed shell
run against the combined mod screenshots "GENERALS VANGUARD" in the main menu with the title bar
reading "Generals Vanguard".

Version 0.5.13 game. The launcher is unchanged from 0.5.12.
