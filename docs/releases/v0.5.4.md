## Generals Vanguard 0.5.4

This is the playability patch: **the options screen and the mouse pointer**. Both were reproduced by
running the game, not guessed at.

- **The first run starts at the monitor's own size.** With no resolution in `Options.ini`, Windows used
  GameData's 1024x768 and then stretched that over a larger desktop, so the 1024-wide options screen was
  clipped at the screen's edges and could not be used. Both platforms now start at the desktop/panel
  size on a first run; a window is no longer a small box in the middle of the screen either.
- **The pointer no longer disappears.** The portable launcher folder ships none of the retail
  `Data\Cursors\*.ANI` files (they are EA's), so `Win32Mouse` loaded no cursors and `SetCursor(NULL)`
  left the game with no pointer at all — in the menus and in a match. The launcher now links the
  player's own `Data\Cursors` from their Zero Hour install into the game folder on every launch, and
  the engine falls back to the system arrow if an ANI is ever missing.
- **The options label says `Generals Vanguard v0.5.4`** instead of `Reforged v0.2.0`; the release
  number now comes from the build, not a leftover 0.2.0 header.
- The Russia menu image overrides stay reverted (they were never the cause, and the custom Russia
  menu images will come back with a test matrix). Russia gameplay, powers, OCLs, build order and icons
  are unchanged.
- Windows package remains built on the 0.4.6 base with the Russia files on top.

Version 0.5.4 game and launcher.
