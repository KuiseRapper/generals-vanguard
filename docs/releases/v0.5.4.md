## Generals Vanguard 0.5.4

- **Reverts the new `MappedImage`/`PlayerTemplate` image overrides.** Those were the only new UI-table
  surface in 0.5.x, and the options screen/cursor broke with them. The Russia gameplay, powers, OCLs,
  build order and icons on disk are unchanged; the side/general/score/load overrides are back to the
  known-good 0.4.6 values.
- This is a **playability first** patch: no cursor/options regression chasing. The custom Russia menu
  images will be reintroduced one at a time with a test matrix once the cursor is confirmed working.
- Windows package remains built on the 0.4.6 base with the Russia files on top.

Version 0.5.4 game and launcher.
