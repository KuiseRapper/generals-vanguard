## Generals Vanguard 0.4.4

- **Fixes `GameData.ini` line 460 / `UserDataLeafName`.** The retail Steam Zero Hour `GameData.ini`
  carries this key. The base game's `GlobalData` parser knows it; the Zero Hour parser's field table
  was missing it, so loading the shipped file threw. It now parses into a member, and the game loads
  the official data again. No clean install or removed files are needed.
- **The false Reforged warning is gone**; it was blaming the wrong thing.
- The duplicate `Data\INI\INIZH.big` move from 0.4.3 stays; the retail game does the same.
- macOS 0.4.4 has the same parser fix and no warning.
