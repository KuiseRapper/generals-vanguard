## Generals Vanguard 0.5.18

- **The credits and Generals Challenge screens are Vanguard's**: the mods' red and gold plates are
  replaced with the fork's own, and the Challenge screen's is plain so "CHOOSE YOUR GENERAL" no
  longer collides with the wordmark.
- **Faction load screens are Vanguard plates.** A skirmish now reads the local player's
  `LoadScreenImage` and draws the five 800x600 plates - USA, China, GLA, ECA and Russia - with the map
  name, a compact player list, the map preview and each player's progress over them.  LAN and the
  Internet keep the retail load screen, with its full player table.  `LoadScreenImage` had been data
  no code read since EA's initial commit; `skirmish_load_check` now holds the wiring, and
  `ZH_LOADSCREEN_SHOT=1` photographs the screen.
- **The army names are labels again**: the two new factions' `DisplayName` is
  `INI:FactionRussia` / `INI:FactionEurope`, which is what the load screen and the lobby look up; the
  literal names were being read as labels and showed `MISSING: 'European'` / `MISSING: 'Russian'`.
- The 0.5.17 retail menus, the animated shell map and the AI fix are unchanged.

Version 0.5.18 game; the combined package carries the data changes.
