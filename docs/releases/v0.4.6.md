## Generals Vanguard 0.4.6

- **The Windows game now finds Zero Hour's own `.big` files.** The engine looks beside its exe;
  Reforged works because it installs into the Zero Hour folder. The portable launcher now hard-links
  every top-level Zero Hour `*.big` (`INIZH.big`, `WindowZH.big`, textures, maps, audio) into its
  game folder, so `Data\INI\Default\Weather.ini` is found and the `Weather.ini` crash stops. If a
  hard link is not possible it copies; the Steam install is never modified.
- **Desktop shortcut.** First run drops **Generals Vanguard** on the desktop.
- The 0.4.4 `UserDataLeafName` parser fix and the 0.4.5 incomplete-data check stay.
