## Generals Vanguard 0.4.1

- **Vanguard startup art.** The startup splash was the Reforged artwork (`Data/Install_Final.bmp`) and the
  menu title was the shipped Generals Zero Hour logo. Both are replaced with Generals Vanguard art, so
  the game starts under its own name.
- **Base game files, still automatic.** The launcher links Zero Hour's shared `ZH_Generals` folder; a
  separate base install is not needed.
- **Update review screen, still there.** Check for updates shows the release notes and Update/Cancel.
- **macOS launcher.** A DMG with a native launcher is attached to the release; it installs the macOS
  game app and launches it with your Zero Hour data folder. This build is for Windows; the macOS
  launcher stays at 0.4.0.
